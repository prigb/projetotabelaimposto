# projeto tabela imposto
Uma planilha criada usando excel para calcular imposto como exercício do Curso do Santander Excel 2026<br>
Consiste em uma tabela para entrar os dados pessoais, inserir entradas e saídas e os informes dos bancos.<br>
Pode ser utilizada para organização financeira e também para simplificar o preenchimento do imposto de renda ou para enviar a planilha para o contador já com todos os dados requisitados.
